# Purple Rain — notas de design

O README combina a arte fornecida com uma apresentação curta em português. Uma tabela HTML simples mantém o símbolo à esquerda e as informações à direita. A arte animada é renderizada como caracteres ASCII em GIF; o desenho textual correspondente também fica disponível em uma seção estática do README.

## Conteúdo preservado

- A apresentação sobre aprender programação e lógica, um projeto por vez.
- Git, GitHub, JavaScript, Python e MySQL como tecnologias em aprendizado.
- A nota de que projetos serão destacados quando estiverem prontos.
- A referência visual à energia de palco de Prince e à apresentação de *While My Guitar Gently Weeps* (2004), sem sugerir afiliação oficial.

## Assets e manutenção

- `assets/ascii-art-original.txt`: arte enviada, aparada apenas das margens vazias.
- `assets/ascii-art-compact.txt`: desenho 60 × 35 usado no README e pelo gerador.
- `assets/purple-rain-dark.gif` e `assets/purple-rain-light.gif`: chuva sutil e transparente para cada tema do GitHub.
- `assets/badges/`: badges SVG locais para as cinco tecnologias em aprendizado.
- `scripts/generate_animation.py`: gerador reproduzível dos GIFs e da prévia PNG.
- `README-SETUP.md`: personalização, publicação e verificação.

O antigo `assets/purple-rain.gif` e o gerador `docs/create_purple_rain.py` permanecem no repositório como arquivos anteriores, mas não são mais referenciados pelo README ativo.
